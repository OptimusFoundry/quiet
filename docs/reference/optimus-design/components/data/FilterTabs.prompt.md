Filter a list or table by status above it.
```jsx
<FilterTabs items={[{ value: 'all', label: 'All', count: 14 }, { value: 'live', label: 'Live', count: 3 }, { value: 'proto', label: 'Prototypes', count: 2 }, { value: 'archived', label: 'Archived', count: 9 }]} />
```
- Use Tabs for switching views; FilterTabs for narrowing a list.
