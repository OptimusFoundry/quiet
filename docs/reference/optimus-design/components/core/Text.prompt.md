Body copy, labels, metadata. Headlines with the molten period should use Headline.
```jsx
<Text size="lg">We cast our own SaaS and mobile apps.</Text>
<Text mono>Studio archive · 2024–2026</Text>
<Text heading={3}>Products people pay for</Text>
<Text color="muted" lineClamp={2}>{longCopy}</Text>
```
- Body is 15–19px, 400. Emphasis is italic of the same weight, never bold.
- color="primary" is molten — punctuation only.
