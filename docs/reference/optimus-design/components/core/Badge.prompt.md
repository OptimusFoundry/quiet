Statuses in tables, notification counts, plan names.
```jsx
<Badge>Draft</Badge>
<Badge variant="success">Paid</Badge>
<Badge variant="warning">Due soon</Badge>
<Badge variant="error">Failed</Badge>
<Badge variant="primary" count={128} />
```
- Status language: success = ink dot · warning = hollow molten dot · error = molten dot + molten hairline.
- Never fill a badge with molten.
