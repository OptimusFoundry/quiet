Glyph icon — use wherever a UI would put an icon. Never draw SVG icons.
```jsx
<Icon name="arrow-right" />
<Icon name="external" size="lg" color="muted" />
<Icon name="close" label="Close" />
```
- Glyphs only. If a real icon set is ever needed, pick a thin 1.5px stroke set and flag it.
- primary/warning/error render molten — use sparingly.
