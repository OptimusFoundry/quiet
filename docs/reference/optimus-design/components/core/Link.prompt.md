Links inside running text and metadata.
```jsx
<p>Read the <Link href="/manual">studio manual</Link> first.</p>
<Link href="https://github.com" external>Source</Link>
<Link variant="muted" size="sm">Privacy</Link>
```
- Inherits size by default so it sits inside body copy.
- primary = 600 weight with a soft underline; use for one emphasised link.
