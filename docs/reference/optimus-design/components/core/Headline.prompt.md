The brand headline: tight bold sans, one italic phrase, ending in the molten full stop. Use for every section title.
```jsx
<Headline size="h2" lead="Heavy software," accent="quietly made" />
<Headline size="display" lead="Software," accent="crafted in" after="precision" />
```
- size: display · h2 · h3 · h4
- One italic phrase per headline. Don't put punctuation in the strings — period adds it.
