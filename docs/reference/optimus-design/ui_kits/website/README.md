# Website UI kit

Recreation of the optimusfoundry.com home page using the design-system components.

- `index.html` — interactive page: sticky NavBar, hero, marquee, studio principles, capabilities accordion, filterable work grid, heat-pass process, contact, footer. "Start a project" opens the commission Dialog; "Send brief" shows a Toast.
- `Hero.jsx` — Hero + Marquee
- `Sections.jsx` — Studio, Capabilities, Work, Process, Contact, Footer
- `CommissionDialog.jsx` — contact form in a Dialog

Built from the public page text only (no source code access). The O·F mark is a dashed placeholder until FoundryMark.svg is supplied. Journal page not recreated.
