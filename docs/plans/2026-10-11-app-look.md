# App look — quiet for SaaS screens

Status: in progress · 2026-10-11 · branch `feat/app-mode`

## Why

agentworks and aijira are built on quiet and read as basic:

- **Rules everywhere.** Pages are built only from hairlines and ink rules (SectionHeader's ink top rule, ink
  table-head rule, divided rows). There are no surfaces, so nothing groups.
- **Links look like text.** `a` and `Link` at rest are plain ink with no underline; molten only on hover. On
  the artifact page "Download", "Run 233f76c2" and "Assistant" can't be told from labels. Table rows
  navigate on click but aren't links.
- **Detail pages are hard to read.** Seven equal small headings, key/values split 900px apart, empty
  sections as loud as full ones, raw MIME types, the transcript as raw text.
- **Page titles are 13px** in the top bar; no page header with status and actions.
- **Statuses blur.** Idle/Orca/Planned/Shipped are all grey pills told apart by a 6px dot.
- **Zero orange.** The guidelines cap molten at "1%, punctuation only, never a fill or button".

All of these follow the guidelines as written, so this is a change to the system, not to the apps.

## Decisions

1. **App look = app density.** Everything below applies under `data-density="app"` and `"compact"`,
   which products already set (QuietRoot `density`). `marketing` (the default, and what the catalog
   renders in) stays pixel-identical to the reference, so `tests/parity.spec.ts` is unaffected.
   Implemented with one SCSS mixin, `app` (`src/styles/_app.scss`), used at the end of each
   component's `q.tokens` block, so app values sit next to the defaults they replace.
2. **Bold brand accent.** In app mode molten is the brand colour, not punctuation: links, primary
   buttons, the active nav item, selected/checked controls, focus rings, progress, tabs, counts that
   need attention, and tinted surfaces for selection and highlights. Body text and large surfaces stay
   ink and paper; molten is still never a section background or a second hue.
3. **Contrast holds.** Text and fills use a darker accent step (`--q-accent-fg` ≈ 4.96:1 on paper);
   `--q-accent` (3.87:1) stays for marks, rings and graphics only.

## Foundations (tier 2)

New tokens, all themes, derived from `--q-accent` so `QuietRoot accent` and product themes follow:

| token | job |
|---|---|
| `--q-accent-fg` | accent text and links (AA on `--q-bg`) |
| `--q-accent-bg`, `--q-accent-bg-hover` | accent fills (primary button) |
| `--q-fg-on-accent` | text on an accent fill |
| `--q-accent-subtle` | tinted surface: selected row/item, highlight, attention badge |
| `--q-accent-border` | tinted edge |

App mode also changes: focus ring → accent; selection → accent-subtle; `--q-border-emphasis`
(ink section rules) → `--q-border`.

## Component retunes (app mode only)

- **Link / base `a`**: accent text, soft accent underline at rest, solid on hover. Muted links stay grey
  with an underline.
- **Button**: primary = accent fill; secondary = hairline outline; ghost hover = subtle fill.
- **Sidebar**: current item = accent-subtle fill, accent icon, 2px accent bar; group labels sans.
- **Tabs / FilterTabs / Pagination / StepIndicator**: current = accent.
- **Checkbox / Radio / Switch / Slider**: checked = accent.
- **Progress**: accent fill.
- **Badge**: status badges get tinted fills (success, warning, error, info, accent) so they read
  without the dot.
- **Table**: head rule from ink to hairline, head on subtle ground, row hover tint, linked rows.
- **SectionHeader**: no ink top rule in app mode; spacing and the heading do the grouping.
- **Card**: subtle-ground option ("panel") as the default container for detail sections.
- **Select**: chevron, not an arrow.

## New components (quiet's own, `src/components/app/`)

- `PageHeader`: eyebrow/breadcrumb, title, status, description, primary and secondary actions, tabs.
- `DescriptionList`: aligned label/value grid (1 or 2 columns); values can be links, code, copyable.
- `Panel`: titled surface section with optional actions and an empty state that collapses.
- `EntityLink`: an ID or name that clearly navigates (icon + accent text), with a mono variant for IDs.
- `FileCard`: file name, kind icon, size, type, download action.
- `Transcript`: a run's messages and tool calls, built on ChatMessage, ToolCall and CodeBlock, grouped by session.

## Decided along the way (2026-10-11 review rounds)

- **Type:** the app look sets Geist + Geist Mono; the body range steps a notch down (body 14, small
  12, page title 24 via `--q-text-3xl`); weight by role (body 450, names/labels/nav 550, strong 620,
  titles 650); text ink a touch softer than the editorial black.
- **Shell:** no desktop top bar. `PageHeader` says where you are (a quiet `back / eyebrow` path); the
  sidebar head holds Search ⌘K and the account menu; phones keep a slim bar for the drawer.
- **Surfaces:** panels on `--q-gray-25` warmed by 1% accent; the selected tint is 6% accent.
- **Tables** lie on the page ground, never on a surface (`Panel variant="plain"` when titled).
- **Lists of files** use `FileCard variant="row"`: the row opens the file, ink names, download on hover.
- **Transcript:** each session is one bordered box; the open head is tinted and ruled off its thread.
- **Dark:** `foundry-dark` takes optimusfoundry.com's dark palette (`#0e0f11`, `#16171a`, `#ff7a3d`).
