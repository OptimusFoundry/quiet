# One look: quiet becomes its own design system

Status: draft for review · 2026-10-12 · supersedes the two-looks model in
[2026-10-11-app-look.md](2026-10-11-app-look.md)

## Why

The app look (built on `feat/soft-ink`: AppShell, panes, soft ink, lava accent, surfaces instead of
rules) is the direction. The editorial "marketing" look, and pixel parity with the Optimus Foundry
reference, now cost more than they give:

- Every component carries two sets of values, wired through `app.look` / `app.reset` / `app.rules`.
- Standalone Claude Design, the reference's home, closes on 2026-12-14.

So quiet drops parity, keeps one look everywhere, and ships it as a major version.

## Decisions

Made in the 2026-10-11/12 session, most of them from side-by-side mockups.

| Area | Decision |
|---|---|
| Scope | Everything. Parity is dropped and the reference mirror becomes history. |
| Looks | One look: the app direction. `data-density` is spacing only. |
| Marketing pages | **Assumed** app-only: no editorial components, no spacious density now. |
| Ink | Headings `--q-fg` #3b3b42, body `--q-fg-body` #5b5b63 (already on the branch). |
| Accent | "Lava": fills `--q-accent-bg` #db3a00, text `--q-accent-fg` #d23300 (oklch, saturated, never mixed with black). Raw molten for marks only. |
| Grounds | Panels `--q-bg-subtle` #fcfbfb (0.5% accent), no edge. Attention surfaces at a 3% accent tint. |
| Rules | Surfaces, not rules, except table rows (faint dividers) and nothing else. |
| Control shape | **Pill** (buttons, inputs, tags, badges, segmented controls). |
| Control size | **Dense**: 32px controls with 13px text; 36px for form fields. |
| Ghost button | Padded, with a soft grey (`--q-bg-subtle`-strength) hover. |
| Tabs | **Segmented surface** by default: the selected tab is a raised chip, with no rule. |
| Table rows | Faint dividers. |
| Overlays | Menus, popovers, dialogs, the palette and toasts float on **shadow only**, with no edge. |
| Icons | One `Icon` component drawing the stroke SVG set (today's AppIcon). Unicode glyphs go. |
| Type | Geist and Geist Mono. Sentence case, no mono caps, no italic flourishes. Mono only for code, IDs and kbd. |
| Secondary content | AppShell panes on desktop. Drawer is the phone fallback only. |
| Wordmark | Kept as the brand lockup, a deliberate exception. |

## Foundations (tier 1 and 2)

- **Promote the app tier-2 values to the defaults.** This covers `tokens/_color.scss`,
  `_typography.scss`, `_space.scss` and `base/_base.scss`, and the app look's
  `@scope` link rule becomes a plain rule.
  - Role tokens: `--q-font-label` is sans, `--q-case-label: none`, `--q-font-hint` is sans,
    `--q-period-display: none`, and the app heading scale.
- **Sizes.** `--q-control-sm|md` and `--q-field-*` move to the dense scale (32 / 36). The editorial
  `lg` sizes are removed or capped.
- **Retarget near-black.** `--q-bg-inverse` and `--q-border-emphasis` (gray-900) are still near-black.
  - `--q-bg-inverse` becomes soft ink, for tooltips and the dark-strip uses.
  - `--q-border-emphasis` is retired.
  - Selected and checked fills read `--q-accent-bg`, as the app look already does.
- **Accent fallbacks.** The `@supports` oklch steps become the primary path. The black-mix
  fallbacks stay only for browsers without relative colour.
- **Overlay tokens.** A tier-2 `--q-shadow-float` takes over the floating layers, and their border
  tokens go to `none`.
- **Density.** `QuietRoot density` accepts `"comfortable" | "compact"`. `"app"` maps to `"comfortable"`
  and `"marketing"` is a deprecated alias of the same, kept for one release.
- **Themes.** Foundry keeps its soft ink. Delete `themes/_foundry-status.scss`; it only styled the
  marketing status look.

## Phases

Each phase is its own PR against `main`, and each leaves `npm run lint && npm run typecheck && npm run build` green.

0. **Land the branch.** Commit and merge `feat/soft-ink`: soft ink, AppShell, panes, lava, panel grey, Billing and Assistant.
1. **Foundations.**
   - Promote the tier-2 values.
   - Make the role tokens sans and sentence case.
   - Dense sizes, `--q-shadow-float`, retarget `--q-bg-inverse`, the density axis with aliases.
   - Icon merge plus the new icon names.

   This must come before the component sweep, so the sweep edits each file once.
2. **Fold the looks.** Mechanical, by folder: `app.look` into the defaults, delete `app.reset`, inline `app.rules`. Then delete `_app.scss` and `check-app-look`. Order matters: fold before delete, or components silently fall back to the marketing values.
3. **Component sweep**, one PR per group: core+forms, display+data+layout, navigation+feedback+overlays, future+charts+chat+app. Covers glyphs, mono caps, rules, italics, the chosen shapes and sizes, and the new variants (ghost, segmented tabs, radio menu, Dialog, Banner, Card, StatCard).
4. **Retire.** Deprecation aliases, rewrite the stories that use retired parts (Panel, AppShell, Assistant, States, guidelines), delete them after one release.
5. **Infrastructure.** `gen.mjs` before the catalog, before reference-compat, before the reference mirror. Then the density story parameters and `_foundry-status`.
6. **Docs, skills, plugin.** In the same PR as the last code change that contradicts them, so reviewers never check against stale rules.
7. **Release.** 1.0.0 ("quiet's own"), with a migration note covering: retired components and their replacements, `density` values, `Icon` names, removed `accent` props, and a re-sync note for vendored apps (`quiet sync --ref v1.0.0`).

## Verification

- **Gates:** lint, typecheck (both passes) and build on every PR.
- **Visual review:** the `visual-reviewer` agent on every story group, in foundry and foundry-dark, at
  1280 and 390, after phases 1–4. The one-look checklist replaces the parity check:
  - no glyph icons, no mono caps outside code, IDs and kbd, no italics
  - no near-black text, no black-mixed accent, no grouping rules except table rows
- **Contrast:** label text at least 4.5:1 (fills, links, muted text), checked by a token script.
- **Keyboard pass per changed interactive component:** focus order, Escape, focus restore, roving
  arrows, reduced motion.
- **Vendored-app check:** run `quiet sync` into a sample app, then `npx quiet check` and its
  typecheck, with the deprecation aliases in place.
